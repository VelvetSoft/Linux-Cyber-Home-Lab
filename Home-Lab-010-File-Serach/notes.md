# Home Lab 010 - Linux File Search & Text Analysis

## Objective

Learn how to locate files, search text, count data, and analyze file contents using common Linux commands.

## Exercises

### Exercise 1 - File Search and Text Analysis

Findings:

* Created and analyzed a text file containing employee records.
* Displayed file contents using the cat command.
* Searched for specific text patterns using grep.
* Counted lines in a file using wc.
* Viewed the beginning and end of a file using head and tail.
* Located files using the find command.
* Sorted file contents alphabetically using sort.

## Lessons Learned

* The cat command displays file contents.
* The grep command searches for text patterns inside files.
* The wc command counts lines, words, and characters.
* The head command displays the beginning of a file.
* The tail command displays the end of a file.
* The find command searches for files and directories.
* The sort command organizes text data alphabetically.
