# Home Lab 007 - Linux Users, Groups and Permissions

## Objective

Learn how Linux permissions, ownership and groups work.

## Exercises

### Exercise 1 - Permission Investigation

Findings:

- Identified the current Linux user and associated groups.
- Investigated file and directory permissions using ls -l.
- Learned how Linux separates permissions for owner, group and others.
- Modified permissions using numeric chmod values (755 and 700).
- Verified permission changes through file listings.
- Practiced symbolic permission modifications using chmod u+x.

## Lessons Learned

- Linux permissions are divided into owner, group and others.
- Read, write and execute permissions are represented by r, w and x.
- Numeric permissions use values 4, 2 and 1.
- chmod can modify permissions using numeric or symbolic notation.
- 755 and 700 are common permission configurations.
