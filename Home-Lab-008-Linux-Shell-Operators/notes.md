# Home Lab 008 - Linux Shell Operators & Documentation

## Objective

Learn how to use Linux documentation and shell operators for command execution and output redirection.

## Exercises

### Exercise 1 - Manual Pages

Findings:

- Explored Linux manual pages using the man command.
- Used the --help option to quickly display command usage information.
- Practiced chaining commands using the && operator.
- Redirected command output to files using the > operator.
- Appended additional output to existing files using the >> operator.
- Executed commands in the background using the & operator.
- Monitored background processes using the jobs command.

## Lessons Learned

- Linux documentation can be accessed directly from the terminal using man and --help.
- The && operator executes the next command only if the previous command succeeds.
- The > operator redirects output and overwrites existing file content.
- The >> operator appends output to the end of a file without deleting existing content.
- The & operator allows commands to run in the background while continuing to use the terminal.
- The jobs command displays currently running background tasks.
