# Linux Cyber Home Lab

## Overview

This project documents my hands-on cybersecurity and Linux learning environment built using Ubuntu Linux in VirtualBox.

## Skills Practiced

* Linux terminal usage
* File permissions and user management
* SSH configuration
* Network scanning with Nmap
* Process and port analysis
* Basic firewall configuration using UFW
* Simple HTTP server setup in Python
* Git and GIthub workflow
* Documentation and project organization 
 
## Tools Used

* Ubuntu Linux
* VirtualBox
* Nmap
* Netstat
* tcpdump
* Python3
* UFW Firewall
* Git
* GitHub
