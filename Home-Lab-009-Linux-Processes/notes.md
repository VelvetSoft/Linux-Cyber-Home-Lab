# Home Lab 009 - Linux Processes & System Monitoring

## Objective

Learn how Linux processes work, how to monitor running processes, manage background jobs, identify process IDs (PIDs), and terminate processes.

## Exercises

### Exercise 1 - Linux Processes and Monitoring

Findings:

* Listed all running processes using the ps aux command.
* Filtered user-owned processes using grep.
* Created a background process using sleep 300 &.
* Monitored background jobs using the jobs command.
* Identified process IDs (PIDs) using ps aux.
* Terminated a running process using the kill command.
* Monitored system activity in real time using top.

## Lessons Learned

* Every running application in Linux is represented as a process.
* Each process has a unique Process ID (PID).
* The ps aux command displays detailed information about running processes.
* The grep command can be used to filter process output.
* Processes can be executed in the background using the & operator.
* The jobs command displays active background tasks.
* The kill command is used to terminate running processes.
* The top command provides real-time monitoring of CPU, memory, and process activity.
